* functionality
Uses a language called D which is s small subset of C
Has its own chapter which we look forward to
Entire functionality of ktrace can be replicated ina  few lines of D highlighting the power of the tool

Allows users to access applications at a very low level  and even change execution flow

* pREVIEW Use cases

save as filemon.d the below to see files opened by preview

syscall::open:entry
/pid == $1 /
{
        printf("%s(%s)", probefunc, copyinstr(arg0));
}
syscall:close:entry
/pid  == $1  /
{
        printf("\t\t = %d\n",arg1);
}
syscall::close:entry
/pid == $1 /
{
        printf("%s(%d) \n", probefunc, arg0);
}
 
then use the command *sudo drace -qs filemon.d [pidof]* on the pid of preview to see current files open
